## Project Overview
This repository contains the codebase for the official website of the RCMS 2026 international conference. The platform serves as the central hub for national and international researchers, academicians, and industry specialists to access event guidelines, view speaker directories, evaluate technical timelines, and register for sessions.

The system is engineered to handle event information delivery, dynamic theme documentation, complex scheduling timelines, and integration with registration portals while aligning with institutional brand guidelines.

---

## Core Modules and Features

### Information Delivery and Navigation
* **Institutional Context:** Integrated structural summaries detailing the history of PSG College of Technology, its Platinum Jubilee celebrations, and the Civil Engineering Department.
* **Responsive Navigation Architecture:** Multi-tier routing for essential domains including Author Guidelines, Speakers, Sponsors, and Contact pages.

### Dynamic Timeline Management
* **Critical Milestone Tracker:** Standardized data schedules tracking abstract collection windows, review submission milestones, camera-ready processing schedules, and dynamic early bird deadlines.
* **Pricing Matrices:** Tiered fee calculation structures breaking down regional configurations, attendee variations, and separate workflow registration pathways for pre-conference workshops.

### Content Cataloging
* **Speaker Portfolios:** Multi-column layout grids showcasing international keynote scholars, national researchers, and specialized workshop coordinators.
* **Technical Track Clusters:** Comprehensive reference segments indexing specific conference fields ranging from Computational tools and AI to Structural Performance and Material Durability.
* **Sponsorship Infrastructure:** Standardized layouts mapping out hierarchical structures from Platinum to Silver sponsorship criteria, combined with active media tracking panels.

---

## Architectural and Technical Stack
* **Front-End Architecture:** HTML5, CSS3, JavaScript (ES6+)
* **UI/UX Optimization:** Responsive UI Breakpoints (Desktop, Tablet, Mobile optimization)
* **Integration Hooks:** Microsoft CMT (Conference Management Toolkit) routing hooks for streamlined manuscript peer reviews.

## Installation and Local Setup

1. Clone the repository to your environment:
   ```bash
   git clone https://github.com
   cd RCMS-PSG-Tech
   ```

2. Launch a local development server or open the core entry page:
   ```bash
   # If using Node.js/live-server environment
   npx live-server .
   ```
